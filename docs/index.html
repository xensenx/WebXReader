WebXReader Documentation

A privacy-focused, browser-based digital library and reader.

Table of Contents

    Overview

    WebXReader is a local-first reading application designed to help you organize, manage, and read your digital library directly in your browser. It is built with privacy in mind and runs mostly on the client side without sending your data to remote servers.

    Architecture

    The application is built using modern web technologies:

    • Framework: React with Vite.
    • Routing: React Router (HashRouter) for client-side navigation.
    • Data Storage:
      • IndexedDB for storing books and reading data.
      • localStorage and sessionStorage for settings and temporary states.
    • Offline Support: Utilizes Service Workers for offline capabilities and caching.

    Supported Formats

    WebXReader supports a variety of document and comic formats. The formats are managed through a central registry.

    • Text-based: TXT, Markdown, HTML, EPUB.
    • Fixed-layout: PDF, CBZ (Comic Book Zip).

    Capabilities such as search, pagination, and theming vary by format depending on the specific engine used.

    Core Features

    • Library Management: Organize your books, track reading progress, search, and filter.
    • Reading Experience: Continuous scroll, pagination, vertical writing mode, and customizable typography.
    • Import/Export: Backup and restore your entire library or settings via JSON files.

    Audit Findings (30-10-2026)

    A recent code audit identified the following key areas:

    • Security: Persistent same-origin XSS path through backup restore (imported backup chapter HTML is stored without sanitization).
    • Functional/Data-integrity defects:
      • Dragging books while a search or filter is active removes hidden books from the saved custom order.
      • Version 2 backup with missing book content can be reported as restored, leaving unreadable library entries.
      • Settings persistence failure is caught and logged as success, allowing incomplete resets.
